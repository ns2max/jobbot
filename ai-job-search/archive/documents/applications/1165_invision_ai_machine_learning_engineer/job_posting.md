# Machine Learning Engineer at Invision AI

**Position:** Machine Learning Engineer
**Company:** Invision AI
**Location:** Toronto, Ontario, Canada (hybrid, 3 days per week in the downtown office)
**Seniority Level:** Entry level
**Employment Type:** Full-time

## About the Company

Invision AI develops a universal AI platform for computer vision applications, powered by
multi-camera technology that creates 3D digital twins. Their solutions serve intelligent
infrastructure and transportation sectors.

## Key Responsibilities

- Develop and deploy ML models across product lines
- Build data-labeling, training, and evaluation systems
- Create evaluation methods linking model performance to business outcomes
- Prototype new capabilities using appropriate technologies
- Optimize models for latency, memory, and power consumption on edge devices
- Diagnose and resolve deployed model issues
- Monitor production performance and identify model drift
- Write maintainable code with thorough documentation
- Participate in design and code reviews
- Collaborate across teams on ML implementation

## Required Qualifications

- Production computer vision model development experience
- Strong Python software development abilities
- Proficiency with PyTorch, TensorFlow, scikit-learn
- CNN and modern architecture knowledge
- Open-source model adaptation skills
- Edge device optimization experience
- Experiment tracking and ML observability knowledge
- Evaluation metric design capability
- Model monitoring and troubleshooting understanding
- Embedded systems knowledge
- Software engineering fundamentals (testing, version control, CI/CD)
- Strong written and verbal communication skills

## Bonus Skills

- Docker / container technologies
- C++ development
- GPU programming and optimization
- Model compression (quantization, pruning, distillation)
- ONNX Runtime, TensorRT familiarity
- Traditional image-processing techniques
- Sensor fusion or geospatial data experience

## Benefits

- Competitive salary package including equity
- RRSP plan
- Health and dental coverage
- 4 weeks holiday
