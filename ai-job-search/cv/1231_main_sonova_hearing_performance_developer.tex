\section*{Professional Summary}
Real-time audio DSP engineer and PhD researcher specializing in algorithms that must run under razor-thin latency and power budgets on constrained embedded silicon. Designed, benchmarked, and shipped a real-time audio pattern detector achieving 14 ms end-to-end inference at F1 0.76 while consuming only 31.4\% CPU on a Raspberry Pi 4 -- a 74x speed-up over the 1038 ms baseline it replaced. This is the same discipline hearing-aid DSP demands: signal-processing decisions that must complete inside an imperceptible latency window on a device with a tiny power envelope. Six years of hands-on work spans STFT/MFCC-family feature extraction, C++17 real-time audio engines (Elk Audio OS, JUCE, VST, OSC), embedded ARM/Raspberry Pi deployment, and power/compute profiling on self-powered hardware -- directly transferable to developing and optimizing signal-processing algorithms for battery-constrained hearing instrument platforms.
