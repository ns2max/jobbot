## Before you send anything

1. **Check each title on LinkedIn first.** Several sources are 2022-2024 press pieces or third-party org charts (TheOrg, CB Insights).
   People move. Every entry has a "Verify" line naming the weak point.
2. **Profile links.** A direct `linkedin.com/in/...` URL is given only where a source published it.
   Everyone else gets a LinkedIn people-search link (name + company), so you can find the right profile in one click. I did not guess any profile URLs.
3. **Connection-note length.** Every connection note is 300 characters or fewer (LinkedIn's limit with Premium). Free accounts get only about 200 characters and a few notes a month.
   On a free account, send the note's first two sentences and keep the rest for the follow-up.
4. **Follow-up timing.** Send the follow-up only after they accept. If there's no reply, nudge once after 7-10 days, then stop.
