# Mode: training — Course/Cert Evaluation

For each course or certification the user asks about, evaluate 6 dimensions:

| Dimension | What it measures |
|-----------|-----------------|
| North Star alignment | Does it move toward or away from the target role? |
| Recruiter signal | How do HMs read this on a CV? |
| Time and effort | Weeks × hours/week |
| Opportunity cost | What can't be done during that time? |
| Risks | Outdated content? Weak brand? Too basic? |
| Portfolio deliverable | Does it produce a demonstrable artifact? |

## Verdicts

- **DO** → 4–12 week plan with weekly deliverables and a scoreboard
- **DON'T** → better alternative with justification
- **DO WITH TIMEBOX** (max X weeks) → condensed plan, essentials only
